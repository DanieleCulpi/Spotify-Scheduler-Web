SPOTIFY SCHEDULER (WEB VERSION) - SETUP GUIDE
============================================

Follow these steps to set up and run the Spotify Scheduler on your computer.

1. CREATE A SPOTIFY DEVELOPER APP
---------------------------------
To use this application, you need to register your own "App" on Spotify's developer portal:

1. Go to the Spotify Developer Dashboard: https://developer.spotify.com/dashboard
2. Log in with your Spotify account.
3. Click "Create app".
4. App name: Spotify Scheduler (or anything you like).
5. App description: Music scheduling automation.
6. REDIRECT URI (CRITICAL): Set this exactly to:
   http://127.0.0.1:5000/callback
7. Check the "Web API" box and agree to the terms.
8. Once created, go to "Settings" in your Spotify app dashboard to find your:
   - Client ID
   - Client Secret

2. INSTALLATION
---------------
1. Ensure you have Python 3 installed on your system.
2. Open a terminal/command prompt in the project folder.
3. Install the required libraries by running:
   pip install -r requirements.txt

3. BUILDING & RUNNING THE APPLICATION
--------------------------------------
1. Double-click "build_exe.bat" to compile the application into a standalone executable.
2. Once the build is complete, open the "dist" folder.
3. Run "spotify-scheduler.exe".
4. The application will start a local server and automatically open your web browser to the dashboard.
5. A tray icon will appear in your system tray (bottom right on Windows) where you can also open the dashboard or quit the app.

4. FIRST-TIME SETUP
-------------------
1. When the dashboard opens for the first time, you will see a mandatory setup screen.
2. Enter the Client ID and Client Secret you obtained in Step 1.
3. Click "Save and Continue".
4. You will be redirected to Spotify to authorize the application. Log in and click "Agree".
5. After authorization, you will be redirected back to the dashboard.

5. TIPS
-------
- SINGLE INSTANCE: If you try to run the app while it's already running, it will simply open a new dashboard tab in your browser and exit the new process.
- BACKGROUND RUNNING: You can close the browser tab anytime; the scheduler continues to run in the background as long as the tray icon is visible.
- LOGGING OUT: If you need to change your Spotify account or credentials, go to Settings and click "Logout (delete cache)".

-----------------------------------------------------------
If you encounter any issues, check the "Console" tab in the dashboard for error logs.
